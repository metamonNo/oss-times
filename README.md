# OSS TIMES — 世界の無料公開Webサービス・ポータル

世界中で無料公開されているWebサービス/OSSを**4時間ごと（1日6回）自動巡回**して掲載するポータル。
「車輪の再発明、その前に。」— 作る前に、もう存在していないか確認しましょう。

## 巡回ソース（8つ＋手動枠・すべて無料/キー不要）

| 種別 | ソース | 内容 |
|---|---|---|
| コード | GitHub | 新着/トレンド/セルフホスト/AI/開発ツールの5クエリ群 |
| コード | GitLab / Codeberg | スター上位の公開プロジェクト |
| AIデモ | Hugging Face Spaces | 無料公開されたAI Webアプリ（その場で使える） |
| SNS告知 | **Show HN** (Hacker News) | 個人開発者の新作発表の本場 |
| SNS告知 | **Reddit** (r/SideProject 等) | 週間トップの個人開発告知 |
| SNS告知 | **Dev.to** (#showdev) / **Bluesky** (#buildinpublic) | 開発者の作品告知 |
| 🇯🇵日本 | **Qiita**（個人開発タグ）/ **Zenn**（個人開発トピック） | 日本の個人開発告知（過去1ヶ月・記事から本体URL抽出） |
| 手動 | `data/custom.json` | 自作サービス・推しサービスを掲載（📌 Pick 表示） |

> **Xについて**: X(Twitter)の公式APIは有料・スクレイピングは規約違反のため、同じ「個人開発の告知文化」を持つ上記の無料ソースでカバーしています。SNS投稿は外部リンク先URLで重複統合し、GitHubリンクの告知は本体巡回と重複するため除外します。

## 主な機能

- **出来立て1000件対応**: GitHub検索をページング収集（直近2週間×スター10以上を深掘り、最大3000件アーカイブ）。1000枚超でも軽い分割レンダリング（120件ずつ「もっと見る」）
- **🇯🇵 日本発を優先**: GitHubを日本語キーワード×過去1ヶ月×スター3〜で深掘り＋Qiita/Zenn巡回。説明文が日本語なら国=日本と自動判定し、「🇯🇵日本発を優先」トグル（日本語UIは初期ON）で最上部に表示
- **🌍 国表示**: GitHubオーナーのプロフィールlocation照会＋ccTLD推定で国を判定。カードに国旗、サイドバー/カテゴリ一覧に国ファセット（アダルトサイトの国別ナビと同じ発想を健全に）
- **アーカイブ＋死活監視**: 一度載せたサービスは検索圏外に落ちても掲載継続。巡回ごとに死活チェックし、404/410が2回連続したものは**非公開/削除としてクローズ**
- **♥ お気に入り**: 各カードの♥でブックマーク（ブラウザ保存）。専用タブで一覧
- **👩‍💻 開発者ピックアップ**: カテゴリ一覧に「今月のリリース数」「総掲載数」の開発者ランキング。クリックでその人の作品一覧
- **用途カテゴリ（🎯）**: 「🏥 介護・医療」「🛒 EC・フリマ・オークション」「📶 ネットワーク・WiFi」など約19の**具体的な生活/業務ドメイン**へ自動分類。技術軸（ジャンル/言語）と掛け合わせた**混合カテゴリー**も自動生成
- **高密度ディレクトリUI**: 左サイドバーのファセット×件数。「カテゴリ一覧」タブで全分類を一望
- **日本語/英語UI自動切替**: ブラウザ言語で自動判定＋ヘッダーでトグル。説明文は巡回時に自動和訳（キャッシュ付き）、日本語UIでは訳文＋ホバーで原文
- **📰 紹介記事の自動生成**: 巡回のたびに新着上位40から**ランダムに3本**を記事化（毎回顔ぶれが変わる）。リポジトリのSecretsに `GROQ_API_KEY`（無料）を設定するとLLMが執筆、無ければ事実ベースのテンプレート記事
- **🤖 AI検索**: 「ヤフオクの出品を楽にしたい」「グループホームのシフト管理」のような日本語の要望から該当サービスを提示。キー無しでも動作、Groqキーで理由付き提案
- リンク集・教材・アダルトは自動除外

## 公開手順（3ステップ・無料）

1. GitHubで新規リポジトリを作成し、このフォルダの中身をすべてpush
   ```bash
   git init && git add -A && git commit -m "initial"
   git branch -M main
   git remote add origin https://github.com/<あなたのID>/<リポジトリ名>.git
   git push -u origin main
   ```
2. **Settings → Pages → Source: Deploy from a branch → main / (root)** を保存
3. **Actionsタブ**でワークフローを有効化（Enableボタンが出た場合のみ）

push直後にActionsが全ソースを巡回し、実データ＋和訳＋記事を生成。以後 **4時間ごと（JST 2/6/10/14/18/22時）** に自動巡回。
（任意）Settings → Secrets → Actions に `GROQ_API_KEY` を追加すると記事がLLM執筆になります。

サイトURL: `https://<あなたのID>.github.io/<リポジトリ名>/`

## 自作サービスを載せる

`data/custom.json` の `items` に追記してpushするだけ（サンプルとして海事系Webアプリ3件を登録済み。自由に書き換えてください）:

```json
{ "n": "サービス名", "h": "https://...", "d": "説明", "t": ["タグ"], "uc": ["🏢 業務・バックオフィス"] }
```

## 掲載申請を受け付ける（他の人の「載せてくれ」対応）

リポジトリに **Issueフォーム**（`.github/ISSUE_TEMPLATE/submit-service.yml`）を同梱済み。

1. 申請者が Issues → 「🚀 サービス掲載申請」から投稿（掲載申請ラベルが自動付与）
2. あなたが内容を確認し、問題なければ **`approved` ラベルを付ける**
3. Actionsが自動で `data/custom.json` に追記 → 次回巡回でサイトに反映（アダルト/詐欺系ワードは自動拒否）

サイトに申請ボタンを出すには `index.html` 冒頭の `SUBMIT_URL` に
`https://github.com/<あなたのID>/<リポジトリ名>/issues/new?template=submit-service.yml` を設定してください。

## 安全対策（危険サイトを載せない）

- 掲載申請はチェックボックスでポリシー同意＋NGワード自動拒否＋**承認制**（approvedラベルを付けるまで掲載されません）
- Secretsに `SAFE_BROWSING_API_KEY`（[Google Safe Browsing API](https://developers.google.com/safe-browsing)・無料）を設定すると、巡回のたびに全掲載URLを照合し **危険判定されたURLを自動除外** します
- 掲載中のサイトにChromeの「危険なサイト」警告が出た場合：そのサイトの**所有者**が [Google Search Console](https://search.google.com/search-console) →「セキュリティの問題」→ 問題を修正して**審査をリクエスト**するのが正規の解除手順です（当ポータル側は上記の自動除外で対応）

## ローカルで実データを取得する

`run-local.cmd` をダブルクリック（要 Node.js 20+）。全ソース巡回＋翻訳で `data/data.json` を生成し、http://localhost:8787 でプレビューします。GitHubに上げる前でも本番同等のデータで確認できます。

## ローカルで試す

`index.html` をダブルクリック。データ未生成の環境ではブラウザが直接API群を叩く**ライブモード**で動作（Reddit除く7ソース・翻訳なし・レート制限あり）。

## カスタマイズ

- 収集条件・閾値: `scripts/fetch-data.mjs`（`CATEGORIES`・各fetcherの最低スコア）。`index.html` 側の同名定義も揃える
- 巡回頻度: `.github/workflows/update-data.yml` の `cron`
- 用途カテゴリ: `USECASES`（正規表現）／ジャンル: `GENRES`／AI検索辞書: `DICT`
- 記事の本数・対象: `makeArticles()`（既定: 1巡回3本・公開45日以内・累計60本保持）

## 構成

```
├── index.html                        # ポータル本体（単一ファイル・依存なし・ja/en対応）
├── data/data.json                    # 巡回データ（自動生成・翻訳キャッシュ兼用）
├── data/articles.json                # 紹介記事（自動生成）
├── data/custom.json                  # 手動掲載枠（自作サービス等）
├── scripts/fetch-data.mjs            # 8ソース巡回+翻訳+記事生成（Node 20+、依存なし）
└── .github/workflows/update-data.yml # 1日3回の自動巡回
```
